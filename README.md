# Ankit Ghosh — Portfolio

A responsive, classic editorial-style personal portfolio. This is a **plain static HTML/CSS site**—no React, npm install, or build step is required. `index.html` works directly in a browser and deploys easily to Vercel.

## Preview locally
Double-click `index.html` to open it in your browser. Keep `Ankit_Ghosh_Resume.pdf` in the same folder so the résumé link works.

## Deploy to Vercel
1. Upload `index.html`, `Ankit_Ghosh_Resume.pdf`, and this README to a new GitHub repository.
2. Import that repository at https://vercel.com/new.
3. Choose **Other** if asked for a framework preset.
4. Leave the build command and output directory blank (or use the root directory as the static output).
5. Deploy.

## Before publishing
- Replace the sample GitHub profile links in `index.html` with each project's direct repository URL.
- Add a direct AWS certificate link if available.
- Check your contact details before publishing.
